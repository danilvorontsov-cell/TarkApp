# 🇪🇪 TarkApp

**TarkApp** («Tark Õpetaja» / «Умный тьютор») — мобильное образовательное приложение-тьютор для русскоязычных школьников в Эстонии, помогающее преодолеть языковой барьер в контексте государственной реформы перехода на 100% эстоноязычное обучение.

---

## 🎯 Миссия и ключевая идея

Школьники (особенно 1–9 классы) теряют успеваемость и испытывают стресс не из-за непонимания предмета (математика, природоведение, биология, физика), а из-за языкового барьера в академических терминах эстонских учебников (**Opiq.ee**, **Koolibri**, **Avita**).

**TarkApp решает эту проблему через адаптационный мостик:**
1. 📷 Ребенок фотографирует задание учебника, рабочую тетрадь или экран с заданием (или бытовой объект в режиме исследователя).
2. 💡 Приложение объясняет суть темы простыми словами через увлечения ребенка (**Minecraft**, **Roblox**, **LEGO**, **Спорт** и любые свободные интересы).
3. 📚 Формирует мини-словарь эстонских терминов урока с примерами и индивидуальной озвучкой правильного произношения.
4. 🎯 Дает пошаговый алгоритм для самостоятельного решения.
5. ✏️ **Интерактивный конструктор ответа (Phrase Builder)**: интерактивные слоты и банк слов (Word Bank) для сборки фразы на эстонском языке.
6. 🔊 **Нейросетевая озвучка Edge-TTS (Zero-Disk In-Memory Streaming)**: потоковый синтез речи на лету (`et-EE-KertNeural` с увеличенной громкостью +20% и `ru-RU-DmitryNeural`).
7. 💾 **История и локальный словарик**: мгновенное сохранение в память устройства с возможностью повторного изучения офлайн.

## 📱 Навигация и разделы приложения (3 вкладки)

1. **📖 Учёба**:
   - Чистый экран для фокуса на обучении.
   - Съемка страницы с камеры смартфона или выбор из галереи (eKool/Opiq).
   - Подробная карточка разбора с озвучкой каждого смыслового абзаца.
   - Интерактивный банк слов для сборки фразы на эстонском.
   - Большая кнопка внизу: «📷 Разобрать следующее задание».
2. **📚 Словарь и История**:
   - **Мой словарик**: накопление всех эстонских терминов из уроков, карточки с примерами и автопроизношением при тапе.
   - **История уроков**: список всех разобранных заданий с датой, типом («Koolitöö», «Maailma Avastaja», «Loodusõpetus») и открытием полного разбора в 1 клик.
3. **⚙️ Настройки**:
   - Профиль ученика: имя, класс (1–12), свободный ввод увлечений и быстрые подсказки.
   - Статистика локального хранилища и управление кэшем.

## 🛡️ Принципы приватности (Zero-PII Architecture)

- **Никаких внешних облачных баз персональных данных и Firebase.**
- **Никаких госидентификаторов:** Никаких Smart-ID, Mobile-ID, e-mail или isikukood.
- **Local-First:** Профиль ученика (класс, интерес, никнейм, история уроков и сохраненные слова) хранится исключительно локально на устройстве (в `AsyncStorage`) и передается на бэкенд только в момент запроса как обезличенный контекст.
- **Zero-Disk In-Memory Audio:** Аудио синтезируется и стримится в оперативной памяти без сохранения файлов на диск.

## 🚀 Быстрый старт

### 1. Бэкенд (FastAPI)

```bash
cd backend

# Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Указать ключ Gemini в .env:
# GEMINI_API_KEY=your_key_here
# GEMINI_MODEL=gemini-3.8-flash

# Запуск dev-сервера
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload
```

Документация Swagger UI доступна по адресу: `http://localhost:8080/docs`

### 2. Мобильное приложение (React Native / Expo)

```bash
cd mobile

# Установка зависимостей
npm install

# Запуск в Expo (для работы с телефоном по локальной сети)
npx expo start -c --lan
```

## 📡 Контракты API

- **`POST /api/v1/analyze-page`**: Принимает фотографию (Multipart FormData) и параметры профиля, возвращает структурированный разбор.
- **`POST /api/v1/analyze-page/json`**: Принимает Base64 снимок для быстрой мобильной передачи.
- **`GET /api/v1/voice/tts?text=...&lang=ru|et`**: Потоковый MP3-аудиопоток (In-Memory Streaming через Edge-TTS).
- **`GET /health`**: Проверка работоспособности сервиса.
